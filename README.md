# AI Portfolio — Nithin Dadi

Four production-ready AI applications demonstrating LLM integration, RAG pipelines, ML explainability, and AI automation.

## Projects

### 1. DataChat — AI Data Analyst
Upload any CSV and ask questions in plain English. AI analyzes the data, generates charts, and explains statistical patterns.

**Stack:** Claude API, PapaParse, Chart.js, Vanilla JS

### 2. DoChat — RAG Document Chatbot
Paste any documents and ask questions. Uses keyword-weighted retrieval with source citations.

**Stack:** Claude API, RAG pipeline, Semantic chunking, Citation system

### 3. PredictIQ — ML Prediction Dashboard
Interactive churn prediction with SHAP explainability, ROC curves, feature importance charts, and AI insight per prediction.

**Stack:** XGBoost simulation, SHAP values, Chart.js, Claude API

### 4. JobMatch AI — Resume Analyzer
Analyzes resume vs job description — match score, skill gaps, radar chart, and tailored recommendations.

**Stack:** Claude API, NLP analysis, Radar visualization, ATS simulation

## Deploy in 30 seconds
1. Fork this repo
2. Go to netlify.com → New site from Git → select repo
3. Deploy — no build step needed

## Local
Just open `index.html` in a browser.
